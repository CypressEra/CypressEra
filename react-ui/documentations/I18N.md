# Internationalization (i18n) Guide

Complete guide for using and extending the i18n system in CypressEra.

## Overview

The project uses **react-i18next** for internationalization, supporting English (en), Chinese (zh), and Spanish (es).

## Quick Start

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation('common');
  
  return <button>{t('buttons.createSession')}</button>;
}
```

## Configuration

The i18n configuration is in `src/i18n/index.ts` and is automatically initialized in `src/index.tsx`.

### Supported Languages

| Code | Language | Native Name |
|------|----------|-------------|
| `en` | English | English |
| `zh` | Chinese | 中文 |
| `es` | Spanish | Español |

### Namespaces

The project uses multiple namespaces for organization:

| Namespace | Purpose | Files |
|-----------|---------|-------|
| `common` | UI elements, buttons, labels | `common.json` |
| `home` | Homepage content | `home.json` |
| `errors` | Error messages | `errors.json` |
| `validation` | Form validation | `validation.json` |
| `aiAssistant` | AI Assistant UI | `aiAssistant.json` |
| `parameters` | Parameter editor | `parameters.json` |

## Folder Structure

## Usage in Components

### Basic Usage

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  
  return <h1>{t('common:buttons.createSession')}</h1>;
}
```

### With Default Namespace

```typescript
const { t } = useTranslation('common');

// Can omit namespace
return <button>{t('buttons.createSession')}</button>;
```

### Multiple Namespaces

```typescript
const { t } = useTranslation(['common', 'home']);

return (
  <div>
    <h1>{t('home:title')}</h1>
    <button>{t('common:buttons.save')}</button>
  </div>
);
```

### With Variables

```typescript
// Translation: "Welcome, {{name}}!"
t('welcome', { name: 'John' })  // "Welcome, John!"
```

### Change Language

```typescript
const { i18n } = useTranslation();

i18n.changeLanguage('zh');  // Switch to Chinese
```

## Adding New Translation Keys

1. Add to English file: `src/i18n/locales/en/[namespace].json`
2. Add to Chinese file: `src/i18n/locales/zh/[namespace].json`
3. Add to Spanish file: `src/i18n/locales/es/[namespace].json`
4. Use in component: `t('[namespace]:newKey')`

Example:

```json
// en/common.json
{
  "buttons": {
    "newButton": "New Button"
  }
}

// zh/common.json
{
  "buttons": {
    "newButton": "新按钮"
  }
}

// es/common.json
{
  "buttons": {
    "newButton": "Nuevo Botón"
  }
}
```

Usage:
```typescript
t('common:buttons.newButton')
```

## Adding a New Language

1. Create folder: `src/i18n/locales/fr/`
2. Copy structure from `en/` folder
3. Translate all JSON files
4. Update `src/i18n/index.ts`:

```typescript
import frCommon from './locales/fr/common.json';
// ... import other fr files

const resources = {
  en: { ... },
  zh: { ... },
  es: { ... },
  fr: {
    common: frCommon,
    home: frHome,
    // ... other namespaces
  },
} as const;

export const supportedLanguages = [
  { code: 'en', name: 'English', nativeName: 'English' },
  { code: 'zh', name: 'Chinese', nativeName: '中文' },
  { code: 'es', name: 'Spanish', nativeName: 'Español' },
  { code: 'fr', name: 'French', nativeName: 'Français' },
] as const;
```

## Adding a New Namespace

1. Create files: `en/newspace.json`, `zh/newspace.json`, `es/newspace.json`
2. Update `src/i18n/index.ts`:

```typescript
import enNewspace from './locales/en/newspace.json';
// ... import for other languages

const resources = {
  en: {
    common: enCommon,
    // ...
    newspace: enNewspace,  // Add here
  },
  // ... same for other languages
} as const;

i18n.init({
  // ...
  ns: ['common', 'home', 'errors', 'validation', 'aiAssistant', 'parameters', 'newspace'],
});
```

## Best Practices

1. **Always specify namespace** for clarity:
   ```typescript
   t('common:buttons.save')  // ✅ Clear
   t('buttons.save')          // ❌ Which namespace?
   ```

2. **Keep keys in sync** across all languages

3. **Use variables** instead of string concatenation:
   ```typescript
   t('welcome', { name })  // ✅
   t('welcome') + name     // ❌
   ```

4. **Test all languages** during development

5. **Use descriptive key names**:
   ```typescript
   t('common:buttons.createSession')  // ✅
   t('common:btn1')                    // ❌
   ```

## TypeScript Support

Type definitions are in `src/i18n/types.ts`. The types are automatically inferred from the JSON files.

## Troubleshooting

### Translations not showing?

1. Check namespace is loaded: `useTranslation(['namespace'])`
2. Verify key exists in JSON file
3. Clear localStorage: `localStorage.clear()`
4. Check browser console for errors

### Wrong language on load?

The language detection order:
1. localStorage (`i18nextLng`)
2. Browser language
3. HTML lang attribute
4. Fallback to 'en'

Force language:
```typescript
localStorage.setItem('i18nextLng', 'en');
```
